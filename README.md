# 🥗 Smart Nutrition CLI

A command-line application built with TypeScript and Node.js to track meals, calculate calories, and analyze daily nutrition.

---

## 🚀 Features

* ✅ Add meals
* 📋 View meals in a clean format
* 🔥 Calculate total calories
* ✏️ Edit meals
* 🗑️ Delete meals
* 📊 Analyze daily nutrition

---

## 🧠 Tech Stack

* TypeScript
* Node.js
* File System (fs)
* JSON-based persistence

---

## 📦 Installation


git clone https://github.com/chrisvillafana-dev/smart-nutrition-cli.git
cd smart-nutrition-cli
npm install
```

---

## ▶️ Run the app


npm run build
node dist/index.js
```
